# Nexus v0.5.2

**状态：正式未签名版。** 本版经维护者例外直接晋升为稳定版（见 `docs/RELEASING.md`），跳过标准 beta 流程和多日 beta 验证窗口；不声称多日真实对话证据或跨平台真机验收。正式安装包只由受保护的 tag 工作流从发版提交重建。

这版是 0.5.1 的补丁，重点在隐私、可靠性和说人话：隐私开关在主进程真正生效，日志和 MCP 输出先脱敏，提醒不再被时钟回拨或语音对话打乱，删掉的记忆不会被重新学回来，报错和批准框也改成日常说法。

## 改了什么

### 隐私与安全

- **保存的隐私开关在主进程生效。** 保存的窗口感知开关关着，或陪伴感知已暂停时，稍后重新显示的提醒不会再去读窗口标题，也不会判断全屏。
- **聊天日志不再保留 Base URL 里的账号密码。** MCP 服务的 stderr 先按行缓冲并脱敏，再进入运行日志。
- **webview 标签已禁用，所有挂载尝试都会被拒绝。** preload 桥少了 48 个渲染层方法，每个 IPC 处理器都必须先做可信发送方检查。
- **`app.asar` 里的语音 sidecar 脚本会被拒绝。** `child_process` 不能执行只存在于归档里的文件，现在会按缺失处理并给出可操作的警告。
- **打字感知默认仍然关着。** macOS 辅助功能被拒绝时不会启动钩子；这两条保护都有测试钉住。

### 可靠性

- **宠物窗口加载失败后能恢复。** 主页面加载失败会重试两次，首次启动仍失败就显示本地重试页。再次显示宠物（包括从托盘打开）会获得一次新的尝试。
- **接管面板重建不再空转。** 隐藏面板重建失败会从 5 秒逐步退避到最多 120 秒；回收前面板会重新检查可见性；系统唤醒或解锁后有 30 秒宽限期。
- **时钟回拨不再跳过后续提醒。** 触发时间晚于当前时间的记录，不会把循环提醒当成已送达；一次性提醒也不会因为回拨重复响。
- **排队的提醒会等语音对话结束。** 正在收音或连续语音占用麦克风时，延后的提醒先等着；会话结束后统一接着念一次，并带 30 秒卡住兜底。全部停止时，排队的提醒会合并成一条聊天记录保留下来。
- **删掉的记忆不会回来。** 单条删除只写入加盐指纹墓碑，不保存原文。之后的抽取、模型 reconcile 和每日整理都会跳过它；手动重新添加会去掉墓碑，清空全部记忆时也会清掉墓碑。

### 文案与设置

- **报错在五种语言里都只说人话。** 原始技术细节进日志，不再直接显示给用户；主进程的错误文案也做了本地化。
- **批准框改成白话并本地化。** MCP 和插件的批准说明覆盖五种语言，路径指向设置 → 连接，撤销路径指向设置 → 连接 → 高级 → MCP。
- **文案和当前设置对齐。** FAQ 指向现在的设置名称，语音状态不再用引擎术语，清理记忆时把小本子叫小本子，集成入口统一叫连接，ElevenLabs 语音标签也已翻译。
- **外链确认可以关掉。** 默认仍然开着；关掉后也仍会先规范化和检查链接，再决定是否打开。
- **启动时不再主动弹权限提示。** 启动只读检查用户已经打开的功能；只有用户自己打开某个功能时，才会请求系统权限或给出设置引导。
- **手动更新写清楚了。** Windows 和 Linux 没有自动更新，需要从官方 GitHub Release 下载并核对 SHA-256。

### 清理与依赖

- 删掉了不再使用的宠物漫游 / free-mode 代码和它的 45ms 计时器。
- Electron 43.8.8，electron-updater 6.8.12。

## 更新通道（v0.5.2）：unsigned-manual

这一版在新的版本范围例外下沿用 unsigned-manual 配置。Windows / Linux 只发布安装包和 `SHA256SUMS-*.txt`，不发布 `latest*.yml` 或 `.sig`，也没有自动更新。macOS arm64 仍是 ad-hoc 签名，只能从官方 GitHub Release 手动下载更新。

## 验收边界

发版提交须通过 `verify:release`、Live2D 烟测、打包烟测、持续运行门禁，以及 `prerelease-check -- v0.5.2`。macOS / Windows / Linux CI 须全绿。不声称跨平台真机证据。

## macOS 未签名自动更新限制

macOS arm64 构建为 ad-hoc 签名，非 Apple Developer ID，也未经公证。Gatekeeper 可能要求右键打开或 `xattr -dr com.apple.quarantine /Applications/Nexus.app`。未签名 macOS 包只会检查新版本并打开官方发布页，需手动下载安装。

## Windows 未签名安装器限制

Windows x64 安装器为 `NotSigned`。SmartScreen 可能提示未知发布者。绕过该提示不是安全保证。请只从官方 GitHub Release 下载并核对 SHA-256。

## 范围边界

- 本版重点是主进程隐私开关与脱敏、提醒和窗口可靠性、白话报错与批准框，以及无用代码清理。
- 不包含签名或公证安装包，也不包含 Windows / Linux 自动更新。
- 不新增遥测。

## 已知问题

- 不声称跨平台真机证据。
- macOS / Windows 构建仍未签名，首次启动可能出现系统信任提示。
