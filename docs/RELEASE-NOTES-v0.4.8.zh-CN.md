# Nexus v0.4.8 — 更靠近你的伙伴

**状态：正式未签名稳定版。** v0.4.8 是当前稳定版本，本文档是它的正式发行记录。
本版从 `v0.4.8-beta.1`（2026-10-15 发布）走标准 beta 流程晋升；计划中的
`0.4.8-beta.2` 已取消。正式产物只由受保护的 tag 工作流从发布提交创建。

v0.4.8 让伙伴更贴近你的日常：它会跟着你正在用的地方看过去，也会察觉你在打字；
面板上就能处理消息，不必先打开聊天；记忆会主动跟进你答应过的事。日常部分也更
安静：三种外观、一条更清楚的设置路径、更小的安装包，以及出错时更容易读懂的话。

## 变化

### 伙伴更靠近你

- 桌宠会跟着鼠标在屏幕上移动，也会大致察觉你在打字，同时不挡住你正在做的事。
- 无边框背景默认关闭，只有你主动打开时才出现；角色是站在桌面上的。
- 只有开启打字感知时才会启用键盘感知。在 Linux 上，单是视线跟随不会再让一个
  可读取键盘的钩子一直运行。

### 三种外观

- 设置里可以切换「温暖伙伴」「跟随系统」和「一点个性」。默认是温暖伙伴。
- 每种外观都有浅色和深色版本，切换后不用重开应用。在 Mac 上，跟随系统会使用
  桌面模糊；其他电脑保留半透明面板。
- 同一套外观也会落到细节上：柔和底色里的线条图标、和外观一致的卡片颜色与圆角、
  浅色的键盘焦点圈，以及「一点个性」里代表你消息的莓果色。

### 面板上的消息

- Telegram 和 Discord 消息会以卡片形式出现在默认面板上。
- 回复和已读留在卡片上；稍后和重要收进小菜单。
- 消息还有文字时，卡片只显示一行预览；同一条消息不会再复制进聊天里。

### 语音

- 首次设置会检查这台电脑的硬件，并据此推荐语音模型。
- 本地语音模型可以在设置里检查并修复。
- SenseVoice 改成在你选择时下载，不再放进安装包；它的转写结果现在能正常返回，
  不会是一段空白。
- GLM-ASR 和 OmniVoice 只在你选择了对应引擎、并打开对应语音开关时启动；任一开关
  关掉就会停止。可选的 Python 服务不会再为所有人常驻内存。
- 设置和语音里的提示改成简短、友好的说法。原始技术文字只写进日志，不再显示在
  界面上。
- 语音界面和本地模型列表在五种语言里都用日常说法，去掉了镜像、软件包和模型格式
  这类面向开发者的内容。

### 会跟进的记忆

- 长期记忆换成更清楚、可核对的记录，伙伴对发生过的事能保持更稳定的理解。
- 聊天里答应的事会成为一个「未完成约定」，之后补充的细节都更新在同一条上。伙伴
  可以在到期前主动提起，在前一晚提出提醒，并在事后问一次有没有完成。
- SOUL 和记忆卡片可以编辑，能看到改动依据，也能一键撤销。SOUL 卡片现在编辑的是
  聊天真正使用的人格。
- 主动跟进共用一份议程，不再分成好几条各自提醒；打开全局暂停时，收集和整理都会
  停止。
- 清理记忆现在会把它从所有地方一起删掉：记忆的搜索副本、记忆页面、应用自己的
  存储日志、陪伴摘要，以及更新时保留的快照。单独删除一条记忆时也会删掉它的快照
  副本；损坏的记忆文件会被另行保留，而不是被直接覆盖。

### 设置与引导

- 设置变成五个清楚的页面，每页只有一个高级展开项，不再是一长墙开关。
- 引导先选语言。文字模型、角色和常驻小窗口先完成；语音、工具、记忆和桌面上下文
  可以稍后再调。
- 首次使用引导在面板里打开，设置里也能再次打开。最后一步点一次就完成；模型保存
  失败会显示可以重试的提示。
- 唤醒词设置完成后，语音模型设置会等到第一次真正使用语音时再出现，不会再提前
  出现在一个隐藏窗口里。

### 更新与应用本身

- 更新会先保存你的数据，并等你确认后才安装。
- 每个窗口只会拿到属于它自己的能力。
- 应用运行在 Electron 43.7.11 上，并补强了崩溃处理和外部链接安全。
- 你看到的倾听、思考、回应用状态来自真实的聊天请求；回复的情绪会按顺序生效，
  难过的回复不会再留着一张开心的脸。

### 更小的安装包与十月模型目录

- 内置角色是官方 Live2D 示例：Mao、Haru 和 Hiyori，默认是 Mao。Live2D 是唯一的
  宠物类型。以前保存的图片或 Sprite 选择会变成 Mao。
- Minecraft 和 Factorio 继续保持隐藏，留到后续版本。
- 2026 年 10 月的模型默认值已经进入，包括 `gpt-6-sol`、MiniMax `MiniMax-M3`，
  以及 SiliconFlow 和 NVIDIA 上的 DeepSeek V4.1 Flash。
- `MiniMax-M2.7` 和 `MiniMax-M2.7-highspeed` 会在 2026-11-18 退役前移出 MiniMax
  选择列表。已保存的选择会迁到 `MiniMax-M3`，原来的套餐不变。
- 自定义 OpenAI 兼容语音转文字默认使用 `gpt-transcribe`，这是 OpenAI 为完整录音
  推荐的模型。仍停在 `gpt-4o-mini-transcribe` 的配置会跟着迁移；你自己填写的
  模型名保持不变。

### beta 期间修好的问题

- 两只眼睛重新一起眨。
- SenseVoice 会返回你说的话，而不是空白转写。
- SOUL 卡片显示并保存聊天真正收到的人格。
- 关闭打字感知后，即使还开着视线跟随，键盘钩子也会停止。
- 延迟打开的语音模型设置会留在可见位置；引导不再出现灰色背景，也不再重复显示
  缺少密钥的提示。
- 隐藏再恢复桌宠、以及完成引导之后，Mao 都会保持可见。
- 五种语言的文案清理去掉了应用做不到的承诺，也去掉了描述内部实现而不是你看到的
  内容的说法。

## 验证边界

发布提交必须通过 `verify:release`、Live2D 烟测、打包 smoke、持续运行门禁，以及
完整的 `prerelease-check -- v0.4.8` 流程，然后才由受保护的 tag 工作流发布产物。
macOS、Windows 和 Linux 的 CI 必须在该提交上全绿。

不会虚构跨平台实体设备验证证据。

## macOS 未签名自动更新的限制

macOS arm64 构建为 ad-hoc 签名，没有 Apple Developer ID 签名，也没有公证。
Gatekeeper 可能要求右键 → 打开，或运行
`xattr -dr com.apple.quarantine /Applications/Nexus.app`。未签名的 macOS 构建只会
检查新版本并打开官方发布页；更新需要用户手动下载并安装。

## Windows 未签名安装器的限制

Windows x64 安装器状态为 `NotSigned`。SmartScreen 可能显示未知发布者提示。绕过
提示不是安全保证。请只从官方 GitHub Release 下载，并核对发布的 SHA-256 校验和。

## 范围边界

- 除 Electron 43.7.11 以及本版本线上已有的生产依赖安全修补外，没有其他依赖变化。
- 不加入遥测、不新增桌面感知来源，也不提供签名安装包。
- 不包含 v0.5 的窗口互动、本地 Kokoro 语音或游戏陪伴。

## 已知问题
