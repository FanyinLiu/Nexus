# Nexus v0.4.5-beta.1 — 维护与加固 Beta

> **Beta。** 这是 v0.4.5 维护版 beta。它不包含任何新运行时功能，也没有用户可见
> 行为变化——与 v0.4.4 稳定版的发布姿态相同。它用于在一大批内部清理落地后、
> 正式 v0.4.5 稳定版发布前做验证：可靠性修复、安全加固和大规模死代码删除。
> 稳定版用户不会被自动升级；beta 安装包仅供手动验证。

## 对用户来说有什么变化

没有用户可见的变化。聊天界面、语音管线、设置布局、陪伴行为与隐私边界与 v0.4.4
完全一致。

v0.4.5-beta.1 在底层携带：

- **可靠性修复**——进程退出时中断的后台 errand 下次启动自动重新排队；删除全部
  聊天会话或记忆后不再复活 legacy 存储；记忆衰减不再跨 dream 周期重复计算；
  聊天 turn 硬超时与工具调用循环边界问题修复；VAD 语音会话在唤醒词监听器重建后
  不再饿死。
- **安全加固**——修复聊天补全路径的 SSRF 绕过；损坏的 `vault.json` 不再被原地
  覆盖；高风险 IPC schema 拒绝未知字段（vault、游戏连接及第三段 rollout）。
- **内部清理**——删除被取代的旧设置面板（约 1.2 万行）和从未启用的 TTS 管线；
  相对 import 统一为显式 `.ts`/`.tsx` 后缀；删除约 270 个未使用导出及其他死代码。
  审计基线（错误脱敏、消息隐私、表单/设置表面）同步迁移到它们现在守护的 V3 实现。

## 已知问题

- 大批内部清理之后，本 beta 需要在 macOS、Windows 和 Linux 上做真实世界验证。
  如果看到任何与 v0.4.4 不同的地方请反馈——尤其是设置、语音对话和夜间 errand 行为。
- 未签名构建的注意事项不变：macOS 首次启动需要右键 → 打开（或移除 quarantine）；
  Windows 可能出现 SmartScreen 未知发布者提示。请对照官方 GitHub Release 的
  各平台 `SHA256SUMS-*.txt` 校验下载。
- v0.5 桌宠行为继续延后，直到 0.4 系列被证明一致。

## 反馈

可使用 GitHub **Beta Validation Report** 模板，或直接描述你观察到的现象。
本次维护 beta 的验证重点：

- 设置：逐个打开每个分区（模型、聊天、记忆、语音、工具、窗口、集成、自主），
  确认与 v0.4.4 一样正常渲染和保存。
- 语音：唤醒词、连续 VAD 对话、流式 TTS 输出。
- 夜间：睡前排队的 errand 能完成并在早晨呈现。
- 记忆：删除全部记忆后重启仍是删除状态（不复活）。
