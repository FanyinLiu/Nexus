# Nexus v0.5.1

**状态：正式未签名版。** 本版经维护者例外直接晋升为稳定版（见 `docs/RELEASING.md`），跳过标准 beta 流程和多日 beta 验证窗口；不声称多日真实对话证据或跨平台真机验收。正式安装包只由受保护的 tag 工作流从发版提交重建。

这版是 0.5.0 的补丁，主要修几件用着用着会踩到的事：打包后的语音、打断以后提醒怎么接着念、宠物卡住时提醒还在不在、以及新用户引导完之后占着的那份内存。

## 改了什么

- **打包后的 Qwen3 语音能正常启动了。** 0.5.0 安装包里漏了 Qwen3 语音所需的文件，选这条语音会起不来；这版补上了，能正常启动了。
- **打断以后，提醒不会丢。**
  - 打字发消息、插话、开新的语音对话：只打断正在念的这一句。排队的提醒和信会等桌宠这轮说完、空闲了再接着念；被打断的那条提醒会重新念一次。
  - 自己点按钮结束语音对话：桌宠先安静大约 15 秒，没有新的对话再接着念。
- **宠物窗口没了或卡住时，面板会接手普通提醒。** 一次性、每天、每周、按间隔重复的都算（天气、搜索、定时聊天这类任务不接管：宠物卡住后缓过来，会补跑最近的一次；如果是宠物或应用重启，30 秒以前到期的不补）；面板藏很久也还能接管，不会因为藏太久自己掉线。启动前大约 30 秒内到期的提醒（包括循环提醒），以前会丢掉，现在会补上；应用关着的那段时间里到期的不会补。
- **新用户引导完以后省一点内存。** 第一次把面板藏起来时，这份面板会被收掉；只要面板没再打开，大约少用 120 MiB。之后第一次再打开会慢一点（大约 0.25 秒），只这一次，打开后就不再省这份内存了。老用户不受影响。

## 更新通道（v0.5.1）：unsigned-manual

这一版沿用 0.5.0 的 unsigned-manual 配置。Windows / Linux 只发布安装包和 `SHA256SUMS-*.txt`，不发布 `latest*.yml` 或 `.sig`，也没有自动更新。macOS arm64 仍是 ad-hoc 签名，只能从官方 GitHub Release 手动下载更新。

## 验收边界

发版提交须通过 `verify:release`、Live2D 烟测、打包烟测、持续运行门禁，以及 `prerelease-check -- v0.5.1`。macOS / Windows / Linux CI 须全绿。不声称跨平台真机证据。

## macOS 未签名自动更新限制

macOS arm64 构建为 ad-hoc 签名，非 Apple Developer ID，也未经公证。Gatekeeper 可能要求右键打开或 `xattr -dr com.apple.quarantine /Applications/Nexus.app`。未签名 macOS 包只会检查新版本并打开官方发布页，需手动下载安装。

## Windows 未签名安装器限制

Windows x64 安装器为 `NotSigned`。SmartScreen 可能提示未知发布者。绕过该提示不是安全保证。请只从官方 GitHub Release 下载并核对 SHA-256。

## 范围边界

- 本版重点是打包 Qwen3 语音、打断只切当前句、宠物掉线时面板接管普通提醒，以及首次引导后回收面板内存。
- 不包含签名或公证安装包，也不包含 Windows / Linux 自动更新。
- 不新增遥测。

## 已知问题

- 不声称跨平台真机证据。
- macOS / Windows 构建仍未签名，首次启动可能出现系统信任提示。
