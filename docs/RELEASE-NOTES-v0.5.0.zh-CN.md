# Nexus v0.5.0

**状态：正式未签名版。** 本版经维护者例外直接晋升为稳定版（见 `docs/RELEASING.md`），跳过标准 beta 窗口；不声称多日真实对话证据或跨平台真机验收。正式安装包只由受保护的 tag 工作流从发版提交重建。

这版就想做一件事：让她活在你的电脑里，不是一个点开才说话的窗口。

她现在会自己看时候。你在全屏、开着勿扰、锁屏，或者正在打字，她先不吭声；你有空了，她再说。

## 改了什么

- 她会先记下来。有话没来得及跟你说，她会记进小本子，然后在气泡里轻轻说一句「我记了件事。」，不再是红点数字了。
- 小本子。有没看的时候点一下她，就能打开她的小本子，最近 15 天想跟你说的都在里面。点一行展开看，顺手点完成、稍后、打开对话都行。点外面或者按 Esc 就合上。
- 提醒只说重点。到点了，通知上只写最要紧的那一句，不把整段话塞进去。
- 提醒小条。提醒可以在桌宠旁边弹一条小条，不抢你打字的光标，过一会儿自己收起来。不想要的话，设置里把「提醒小条」关掉就行。
- 鼠标靠近她，她会看你一眼。不会一直看，隔一会儿才会再看。
- 打字的时候她不打扰你。这个默认关着，在设置 → 窗口里打开「打字感知」。开了也只知道你在不在打字，不记你按了什么键。
- 回来的时候，她会告诉你你不在时攒了几条，不用自己去翻。
- 日记改叫「每日记录」，就是她每天帮你记的那一页。
- 写给以后的信。到日子了，她会说一句「你 N 天前写给今天的信，到了」，下面是你当时写的原文，一个字不改。她只念这一句，旁边有人也看不到信里写了啥。

## 隐私

打字感知默认关，开了也不记按键。麦克风你不点就不开。通知和记录里只有重点，不放全文。

## 验收边界

发版提交须通过 `verify:release`、Live2D 烟测、打包烟测、持续运行门禁，以及 `prerelease-check -- v0.5.0`。macOS / Windows / Linux CI 须全绿。不声称跨平台真机证据。

## 更新通道（v0.5.0）

音梵已于 2026-11-06 明确允许本版采用未签名更新通道，范围仅限 v0.5.0。由于没有配置 `NEXUS_UPDATE_SIGNING_KEY`，本版不发布 Windows/Linux 更新清单。Windows 和 Linux 在 v0.5.0 **没有自动更新**：下一个版本请到官方 GitHub Releases 手动下载，并核对 `SHA256SUMS-windows.txt` / `SHA256SUMS-linux.txt`。macOS 未签名版本本来就是手动下载。不要对外声称这一版的 Windows/Linux 自动更新可用。

缺少 key 不会放宽发布门禁。tag 来源、preflight、`prerelease-check`、打包、各平台校验和、远端资产闭合检查都照常执行；只是不发布未签名清单。

## macOS 未签名自动更新限制

macOS arm64 构建为 ad-hoc 签名，非 Apple Developer ID，也未经公证。Gatekeeper 可能要求右键打开或 `xattr -dr com.apple.quarantine /Applications/Nexus.app`。未签名 macOS 包只会检查新版本并打开官方发布页，需手动下载安装。

## Windows 未签名安装器限制

Windows x64 安装器为 `NotSigned`。SmartScreen 可能提示未知发布者。绕过该提示不是安全保证。请只从官方 GitHub Release 下载并核对 SHA-256。

## 范围边界

- 本版重点是主动投递（小本子）、提醒要点、提醒小条、鼠标靠近与打字安静、离开计数，以及每日记录文案。
- 不包含声纹唤醒（留给 0.6）、摄像头（留给 0.7）、签名/公证安装包。
- 不新增遥测。
