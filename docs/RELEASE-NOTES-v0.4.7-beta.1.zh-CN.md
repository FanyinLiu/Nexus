# Nexus v0.4.7-beta.1 — 形象兼容性与诊断

**状态：Beta 发布候选，不是公开稳定版。** 当前稳定版仍是 v0.4.5。
v0.4.6-beta.1 作为历史验证证据保留；它的多日验证窗口尚未关闭，因此没有
晋升为稳定版。

v0.4.7-beta.1 让导入的 Live2D 模型在激活前更安全、出问题时更容易修复：
复制或切换前检查 Cubism 模型及其本地资源，区分真正会阻止渲染的问题与只会
限制互动的问题，并把资源证据写入现有三模型烟测报告。

## 主要变化

### 激活前验证

- 导入的 `.model3.json` 必须声明 Moc 核心文件和至少一个纹理；已声明的 Moc、
  纹理、动作、表情、物理、姿势、用户数据和显示信息文件都必须存在。
- 绝对路径、父目录穿越以及指向模型文件夹之外的符号链接，会在模型激活前被
  拒绝。
- 无效模型不会复制进本地模型库，也不会替换当前伙伴。

### 不把能力受限误判为不可用

- 缺少 Moc、纹理或已经声明的资源时会阻止激活，因为运行时无法安全加载。
- 完全没有声明动作或表情的模型仍可能正常显示。Nexus 会导入它，同时清楚
  提示对应互动能力受限，而不是拒绝一个仍可用的形象。

### 可操作且保护隐私的诊断

- 五语言提示会区分模型定义、Moc、纹理、动作、表情、辅助资源和不安全路径。
- 修复建议会提示把 `.model3.json` 引用的资源保留在同一模型文件夹后重试。
- 渲染器与审计边界只接收资源类别和数量，不接收私有本地路径或模型内容。

### 可长期留档的切换证据

- Mao、Haru、Hiyori 烟测报告升级到 schema 4。
- 每次冷启动和同页切换都会记录 Moc 声明状态以及纹理、动作、表情数量；门禁
  固定校验三个内置模型的预期资源画像，同时保留首帧、截图、上下文丢失和单一
  画布检查。
- 打包持续运行的 CDP 快照也会保留同一组资源标记，供发布验证使用。

## Beta 验证边界

发布审查前必须完成：

- `npm run verify:release`
- `npm run live2d:three-model:smoke`
- `npm run package:dir:smoke`
- `npm run runtime:packaged-sustained`
- `npm run prerelease-check -- v0.4.7-beta.1`
- 发布提交在 macOS、Windows、Linux 的 CI 全绿

beta 发布后仍需要真实第三方导入模型反馈。自动化夹具可以证明阻断、受限、就绪
三类判断与隐私边界，但不声称兼容每一种第三方 Cubism 导出工具。

## 已知问题

- 第三方 Cubism 导出工具可能使用当前 Cubism 3/4 模型引用集合之外的资源字段；
  如需反馈，尽量提供最小化且已脱敏的夹具，不要上传私人模型包。
- 没有声明表情或动作的模型可以显示，但修复模型包前无法提供对应互动。
- v0.4.6 尚未完成稳定版验证；这个更新的 beta 不会豁免或倒推关闭该窗口。

## macOS unsigned auto-update limitation

macOS arm64 beta 采用 ad-hoc 签名，不是 Apple Developer ID 签名，也未公证。
Gatekeeper 可能要求右键打开，或执行
`xattr -dr com.apple.quarantine /Applications/Nexus.app`。应用只打开官方发布页，
用户需要手动下载并替换应用。

## Windows unsigned installer limitation

Windows x64 安装器为 `NotSigned`，SmartScreen 可能显示未知发布者。绕过提示
不是安全保证；只应使用官方 GitHub Release，并核对发布的 SHA-256 校验和。

Linux x64 仍由受保护工作流生成 AppImage、deb、tar.gz、更新元数据和
`SHA256SUMS-linux.txt` 完整闭包。

## 范围边界

- 不升级依赖，不新增存储迁移或持久数据。
- 不新增桌面感知、遥测或外部服务。
- 不包含 v0.5 的移动、鼠标/打字反应、实体设备唤醒或最近扬声器路由。
- 单独完成稳定版验证和晋升前，v0.4.5 仍是稳定更新目标。
