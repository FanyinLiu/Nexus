# Nexus v0.4.6 升级计划（2026-08-03）

状态：已放弃（2026-08-03 被 `V0.4.6_EXECUTABLE_TASKS.md` 的「记忆可信度」主题取代；
放弃原因见该文件末尾「已放弃方向」）。2026-08-06 再注：取代本计划的记忆可信度
主题已随 v0.4.5 stable 提前发布，0.4.6 版本号当前不承载任何既定主题。本文件仅作
历史记录保留。

主题：**"时光记忆"（Time & Memory）**——把已建好数据管道、尚未接入 UI 的
记忆/情绪功能补齐为用户可见的"回忆"体验，为 v0.5 桌宠情绪表现打数据基础。

调研依据：`docs/MARKET_RESEARCH-2026-08.md`。竞品参照：ackem（记忆整合/
矛盾检测/时间系统）、yoji（情绪联动）、my-neuro（Live2D 情绪表现）。

---

## 背景与定位

- v0.4.3 起连续 3 个版本无用户可见新功能（0.4.3 透明视图模型、0.4.4/0.4.5 维护）。
- v0.5 是桌宠行为大版本（mouse/typing/idle 反应），工程量大，需要中间的价值交付。
- 代码库已有完整数据管道但无 UI 的功能：yearbook（年度回顾，含测试与基准）、
  mood map（月度情绪）、letter（周日信）、userAffectTimeline（情绪数据采集）。
- 定位原则：**用户可见价值、低风险（管道已就绪）、本地优先（不碰隐私边界）、
  为 v0.5 铺路**。不抢 v0.5 的桌宠行为功能。

## 范围（In Scope）

### P0 — 年度回顾（Yearbook）UI 接入

- 现有资产：`src/features/yearbook/`（yearbookAggregator + yearbookRender，
  已有属性测试 + 10k 条基准）、`moodMapBinning`、`coregulation`、情绪时间线采集。
- 交付：
  1. 年度回顾视图（设置内入口 + 对话内触发），展示：年度对话统计、情绪曲线、
     重要记忆高亮、关键词云（本地生成）。
  2. 触发时机：年末自动生成草稿 + 用户手动生成（任意时间）。
  3. 导出：本地 HTML 导出（yearbookRender 已有能力）。
- 验证标准：数据全部本地、无新感知来源、无精确时间语言（沿用粗粒度原则）、
  生成耗时 < 3s（10k 条基准下）。

### P1 — 月度情绪地图 UI

- 现有资产：`userAffectTimeline`（VAD + LLM 情绪读取已采集）、`moodMapBinning`、
  `MonthlyRecap` 概念（stateTimeline 注释）。
- 交付：月度情绪视图（情绪分布、趋势、与重要记忆关联），设置记忆面板内嵌。
- 验证标准：与年度回顾共享数据源，无重复采集。

### P1 — 记忆增强（借鉴 ackem 的 consolidator / contradictionDetector）

- 现状：Nexus 记忆有 decay/recall/dream，但无整合与矛盾检测。
- 交付（选做，视 0.4.5 beta 反馈优先级）：
  1. 记忆整合：dream 周期内合并相似记忆（基于现有 embedding/vectorSearch）。
  2. 矛盾检测：新记忆与旧记忆冲突时标记，交由用户在记忆面板确认。
- 验证标准：现有记忆测试全绿 + 新增整合/矛盾测试；整合不影响 recalled 语义。

### P2 — 记忆迁移默认化

- 现状：SQLite local-data 迁移（vault/chat/memory）被 `VITE_NEXUS_ENABLE_LOCAL_DATA_MEMORY_MIGRATION=1`
  flag 门控，未默认启用。
- 交付：记忆域迁移默认启用（vault/chat 已默认？需核实），迁移面板从"隐藏"
  转为正式设置入口；回滚路径保留。
- 验证标准：迁移测试全绿、回滚矩阵文档更新。

## 范围外（Out of Scope）

- v0.5 桌宠行为（mouse/typing/idle 反应）——留给 v0.5。
- 新感知来源（屏幕/音频主动采集）——违反 0.4 隐私边界。
- 情绪-主动聊天联动（yoji 式定时打扰）——与"克制陪伴"定位冲突，仅评估不实施。
- 角色扮演/Galgame 叙事（LingChat 式）——方向不符。
- 消息网关扩展（hermes 式 16 网关）——超出陪伴定位。

## 里程碑

| 阶段 | 内容 | 门禁 |
|---|---|---|
| M1（0.4.6-beta.1） | P0 年度回顾 + P1 月度情绪地图 UI | verify:release 全绿、隐私审计（无新感知源）、i18n 5 语言 |
| M2（0.4.6-beta.2 如有） | P1 记忆整合/矛盾检测 | 记忆测试全绿、decay 语义不变 |
| M3（0.4.6 stable） | P2 记忆迁移默认化 + 全部 beta 反馈修复 | prerelease-check 30 项、三平台 CI、打包 smoke |

## 发布流程

- 走标准 beta 流程（同 0.4.5）：`v0.4.6-beta.1` → 验证窗口 → stable `v0.4.6`。
- 若 0.4.5 beta 反馈量大，M1 顺延并入 0.4.6 开头（0.4.6 不承诺日期）。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 年度回顾生成耗时（10k 条基准 3s 内，但真实数据更多） | 懒加载 + 分块处理 + 进度提示；基准测试覆盖 100k 条 |
| 记忆整合误合并（语义损失） | 保守阈值 + 整合前后快照 + 用户可见的整合记录 |
| 记忆迁移默认化引入数据问题 | 回滚矩阵保留；迁移前自动备份（已有 backup envelope） |
| 0.4.5 beta 反馈占用资源 | 反馈修复为最高优先级，本计划可顺延 |
