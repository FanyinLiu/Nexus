# Nexus v0.4.6 计划：「记忆可信度」（Memory Integrity）

状态：已提前发布（2026-08-06 更新）。本计划的主题（记忆可信度：P0 矛盾检测 + 搭车 F 迁移默认化）已随 **v0.4.5 stable** 在 2026-08-06 发布——它们在 v0.4.5 beta 验证窗口内合入 main 并一同晋升稳定版，因此 M1/M3 里程碑作废，0.4.6 版本号不再承载本主题。仅剩可选 P2（recallTrace 接入展示）留给未来版本评估。前身计划（时光记忆/年度回顾）经讨论放弃——原因记录于本文件末尾。

**主题**：把记忆系统从"能跑"变成"可信"。连续 3 个版本无用户可见功能后，本版本交付**对话层可感知的能力**：她记得更准、更少自相矛盾、整理记忆的过程可见可撤销。
**原则**：互动型能力（改变日常对话），不做展示型 UI（看数据/回顾类，已否决）；本地优先；为 v0.5 桌宠行为铺路（记忆是行为的内容源）。

## 范围

### P0 — 矛盾检测（新能力，ackem contradictionDetector 参照）【已完成】

- [x] `src/features/memory/contradictionDetector.ts`（纯函数，可测）：
  - `rankContradictionCandidates(memories, similarityFn)`：仅对新写入记忆 × 旧记忆做两两语义相似度（注入式，测试可替），过滤同簇（relatedIds）、已 superseded、自身对；排序 + top 20 截断。
  - `judgeContradictionPair(a, b, similarity)`：三档——`likely`（相似 ≥ 0.85 且情感极性相反）/ `possible`（相似 ≥ 0.8）/ `none`。
  - `applyContradictionResolutions(memories, resolutions)`：落地为 MemoryItem 新字段 `supersededBy` / `supersededAt` / `supersededPending`；幂等；已确认不覆盖，pending 可升级。
  - `detectContradictions(newMemories, existingMemories, deps)`：异步编排（embed 新记忆一次 + keyword 预筛 top 8 旧记忆再 embed，限定成本）。
- [x] MemoryItem 类型 + `normalizeMemoryItemsForStorage` 白名单加新字段（已确认白名单裁剪行为并测试覆盖）。
- [x] dream 集成：useMemoryDream 在 decay 后、聚类前跑检测（现有 `embedMemorySearchText`，无额外 LLM 成本）；失败降级为 debug 事件不阻塞 dream。
- [x] recall 降权：`rankMemories`（keyword 路径）+ `scoreItem`（vector/hybrid 路径）。
- **两档全自动（2026-08-03 决策：砍掉 P1 确认 UI）**：`likely` → ×0.3（新立场赢）；`possible` → ×0.6（温和防误伤）；零用户交互、零新 UI。`supersededPending` 语义 = 轻度降权标记（调试用）。
- **验收**：✅ 22 个新测试；✅ 全量 3036 测试全绿；✅ 无新感知来源；✅ `verify:pr` 全绿（EXIT 0）。

## 风险与对策

| 风险 | 对策 |
|---|---|
| 误判矛盾（语义损失） | 保守阈值；`likely` 才自动降权；`possible` 仅标记交用户；不删除任何记忆 |
| 存储归一化裁剪新字段 | 先查 normalizeMemoryItemsForStorage 白名单，测试覆盖 |
| O(n²) embedding 开销 | 仅新记忆 × 旧记忆；候选对数上限；复用 embedding 缓存 |
| 降权影响既有 recall 语义 | 降权系数保守（0.3）+ 现有 recall 测试全绿为门禁 |

## 已放弃方向（记录）

- **年度回顾设置页 UI**（曾实现后回滚）：低频、空态常态、无动作闭环；价值主体是创造者（作者），非终端用户。数据层 `yearbookAggregator`/`yearbookRender`（仓库既有资产）保留未动。
- 周信情绪段落（D）、子 Agent 异步任务（E）：用户明确排除。
- 展示型数据统计/可视化：一律不做（作者向）。
